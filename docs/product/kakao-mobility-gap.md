# Kakao T 참고 기반 MetroLive 확장안

공식 Kakao Mobility 자료를 참고하면 Kakao T는 택시 호출만이 아니라 목적지 입력 이후의 이동 옵션 비교, 주차·바이크·내비, 버스·기차·항공 예약, 탑승 이후 안내를 하나의 이동 흐름으로 묶는다.

참고:

- [Kakao Mobility 위치기반 서비스 목록](https://policy.kakaomobility.com/viewer/?languageCode=en&pageCode=LOCATION&subPageCode=service_list&version=5)
- [Kakao T 서비스 소개](https://www.kakaocorp.com/page/service/service/KakaoT/?lang=ENG)
- [Kakao T App 서비스 설명](https://apps.apple.com/us/app/kakao-t/id981110422)

## MetroLive에 가져올 것

| Kakao T의 패턴 | MetroLive 적용 | 우선순위 |
|---|---|---|
| 목적지 입력 후 이동수단 비교 | 빠른길·덜 붐비는 길·무장애길을 이미지 카드와 실제 경로로 비교 | P0 |
| 지도에서 주변 이동수단 확인 | 지하철·버스·화장실·출구·마지막 1km 이동을 위치 기반으로 표시 | P0 |
| 탑승 전후 안내 | 다음 열차, 환승 방향, 하차 1정거장 전, 무장애 출구를 순서대로 안내 | P1 |
| 주차·바이크·라스트마일 | 역 주변 자전거/킥보드/주차/택시 환승 가능성을 정보 카드로 제공 | P1 |
| 예약·결제·여행 묶음 | 현재는 외부 연결/공공데이터 링크로 시작하고, 예약·결제는 별도 제휴 이후 진행 | P2 |

## 차별화할 것

Kakao T가 이동수단의 폭과 호출·예약 흐름에 강하다면, MetroLive는 수도권 대중교통의 상태 해석에 집중한다.

- 혼잡도와 지연 원인을 노선도 위에서 설명
- 빠른길뿐 아니라 덜 붐비는 길과 무장애길을 동등한 선택지로 제공
- 역사 내부 화장실·엘리베이터·출구·지하상가까지 연결
- 모든 실시간 값에 수집 시각·신뢰도·대체 데이터 여부 표시
- 이미지 카드는 장식이 아니라 각 이동 의사결정의 의미를 설명하는 역할로 제한

## 개인정보·개인화 원칙

- 쿠키를 읽지 않고 MetroLive가 직접 저장한 localStorage/Zustand 데이터만 사용한다.
- 최근 검색·즐겨찾기·성공한 경로의 요일/시간대만 기기 안에 저장한다.
- 개인화는 기본 활성화하되 `개인화 끄기`, `학습 데이터 삭제`, `최근 경로 삭제`를 제공한다.
- 서버로 이동 패턴을 보내지 않는 것을 기본값으로 한다.
