# Let's Metro 데이터 확장 로드맵

현재 서비스가 가진 역·노선·도착·버스·화장실·시설·날씨 데이터에 아래 공식 소스를 결합하면 “어디로 갈까”를 넘어 “지금 이동해도 괜찮은가”까지 안내할 수 있다.

## 우선 연동

1. **서울교통공사 30분 단위 혼잡도**
   - 역·호선·상하행·요일·30분 단위 평균 혼잡도
   - 현재 `useCongestion`의 실시간 인구 기반 수치와 함께 `예상 혼잡도 / 현재 혼잡도`로 구분
   - [서울교통공사 지하철혼잡도정보](https://data.seoul.go.kr/dataList/OA-12928/F/1/datasetView.do)

2. **TOPIS 돌발·통제·공사 정보**
   - 버스 우회, 도로 통제, 행사·공사로 인한 지연 원인을 경로와 역 인스펙터에 연결
   - 지연 원인을 임의 문구로 만들지 않고 `원인·영향 구간·해제 예정`으로 표시
   - [서울시 교통정보 시스템 TOPIS](https://topis.seoul.go.kr/openMain.do)

3. **서울교통공사 역사 편의시설 위치정보**
   - 엘리베이터·에스컬레이터·화장실·수유실·ATM·물품보관함의 위치·운영 상태
   - 현재 정적 `station-facilities.json`을 최신 API/파일과 정기 대조
   - [서울교통공사 역사 편의시설 안내](https://www.data.go.kr/data/15133897/fileData.do)

## 차별화 기능 후보

- **무장애 신뢰도**: 엘리베이터 운영 여부, 경사로, 점자·음성유도기 데이터를 합쳐 “전 구간 이용 가능” 여부를 판정
- **환승 리스크**: 환승거리·계단 수·엘리베이터 우회·최근 장애를 함께 보여주는 경로 점수
- **날씨 기반 이동 제안**: 강수확률·강수량·풍속을 이용해 우산 없는 지하 연결 경로를 자동 우선
- **공공화장실 신뢰도**: 개찰구 안/밖, 운영시간, 장애인 화장실, 최근 확인 시각을 한 줄로 표시
- **운영 품질**: 데이터별 마지막 수집 시각과 신뢰 상태를 인스펙터에 표시

## 보류 데이터

- 재난문자·기상특보는 이동 경로를 실제로 바꿀 수 있을 때만 노출한다.
- CCTV는 개인정보·저장·트래픽 비용을 고려해 링크형 또는 썸네일형으로 제한한다.
- 민간 지도·택시 API는 라이선스와 비용을 확인한 후 도입한다.
