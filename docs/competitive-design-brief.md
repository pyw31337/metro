## 차별화 문장

> MetroLive는 “어디로 가는지”만 알려주는 지도가 아니라, **지금 어떤 이동이 나에게 가장 덜 힘든지** 보여주는 지도다.

차별점은 단순한 노선 수가 아니라 다음 결합이다.

1. 도착정보의 신뢰도와 데이터 나이를 함께 표시
2. 혼잡·지연·날씨·환승을 계산한 이동 품질
3. 역 내부 출구·엘리베이터·화장실까지 연결
4. 빠른 경로뿐 아니라 덜 붐비고 계단 없는 대안 제시
5. 공식 데이터와 사용자 신호를 구분하여 설명

## Uber-like map-first design

### 공통 레이아웃

```text
┌─────────────────────────────────────┐
│  어디로 갈까요?       현재위치 ◉     │  ← floating search
│                                     │
│             지도 배경                │
│      역·버스·혼잡·시설 레이어         │
│                                     │
│  [빠름] [덜 붐빔] [무장애]             │  ← floating chips
├─────────────────────────────────────┤
│  2호선 강남행  3분  신뢰도 높음       │
│  총 34분 · 환승 1 · 화장실 120m       │  ← bottom sheet
└─────────────────────────────────────┘
```

### 디자인 원칙

- 지도는 항상 살아 있는 배경으로 유지
- 검색과 추천은 floating surface로 겹침
- 지도 마커는 적게, 행동 가능한 정보만 표시
- 열차 위치보다 다음 행동을 강조
- 신뢰도는 색상만으로 표현하지 않고 텍스트로도 표현
- 접근성 모드에서는 카드·음성·고대비를 우선

## 디자인 시안 변형

### A. Ride Cockpit — 추천

Uber의 호출 화면처럼 지도 위에 출발·도착과 추천 카드를 띄운다. 가장 빠른 출시와 반복 사용에 적합하다.

### B. Station Inside-Out

역에 들어간 순간부터 출구·환승·화장실·엘리베이터를 안내한다. 교통약자와 초행 이용자 차별성이 가장 강하다.

### C. Urban Pulse

혼잡도·지연·사고·날씨를 지도 위 색상과 그래프로 표현한다. 브랜드 임팩트는 크지만, 초기 사용자에게는 정보량이 많다.

권장 조합은 **A를 홈 화면**, **B를 역 상세**, **C를 탐색/운영 화면**으로 사용하는 것이다.
