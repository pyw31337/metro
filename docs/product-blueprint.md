# MetroLive product blueprint

## 제품 정의

MetroLive는 열차를 지도에 찍는 서비스가 아니라, 현재 위치와 목적지 사이에서 **가장 빠르고 덜 붐비며 이동 가능한 방법을 결정해주는 지도 기반 이동 어시스턴트**다.

핵심 질문은 세 가지다.

1. 지금 출발하면 어떤 경로가 가장 좋은가?
2. 지연·혼잡·환승·접근성 때문에 다른 경로가 더 나은가?
3. 이동 중 다음 행동(탑승·환승·하차·화장실·출구)을 언제 해야 하는가?

## 주 기능

### 1. Map-first journey cockpit

Uber와 유사하게 지도를 전체 배경으로 사용한다. 상단에는 출발지/목적지 검색, 하단에는 이동 추천 카드가 떠 있는 구조다.

추천 카드는 시간만 보여주지 않는다.

- 총 소요시간
- 다음 열차/버스 도착
- 환승 수와 도보시간
- 혼잡도
- 엘리베이터/무장애 가능 여부
- 화장실 접근성
- 장애·공사·날씨 영향
- 데이터 신뢰도와 마지막 관측시각

### 2. Station utility layer

역을 선택하면 지도 위에 역 내부의 실제 이용 정보를 겹친다.

- 빠른 환승 방향
- 빠른 하차 칸
- 엘리베이터와 에스컬레이터
- 화장실·수유실·ATM
- 출구별 목적지
- 역사 안내도

### 3. Confidence-first realtime

실시간 열차 위치가 역 이벤트 기반 추정이라는 점을 감추지 않는다.

```text
2호선 강남 방면 · 3분 후
도착정보 38초 전 · 신뢰도 높음
```

위치 추정이 오래되면 회색 상태로 전환하고, 도착정보·시간표·추정값을 구분한다.

### 4. Accessibility route

일반 최단경로와 별도로 다음 경로를 제공한다.

- 계단 최소
- 엘리베이터 우선
- 유모차 가능
- 휠체어 가능
- 화장실 포함
- 환승거리 최소

### 5. Calm alternatives

“가장 빠른 경로” 하나만 제시하지 않는다.

- 가장 빠름
- 가장 덜 붐빔
- 환승 최소
- 계단 없음
- 화장실 포함

## 사용자 흐름

```text
현재 위치/목적지 입력
        ↓
실시간 데이터·혼잡·장애·접근성 결합
        ↓
추천 경로 3개 비교
        ↓
지도 위 이동 진행
        ↓
환승·하차·출구·시설 알림
```

## 독립 서비스 구조

```text
apps/web                 # PWA 사용자 화면
apps/ops                 # 데이터 품질·운영 화면
packages/transit-model   # 역·노선·정류장 표준 모델
packages/routing-engine  # 다중 모드 경로
packages/eta-engine      # 도착 예측·신뢰도
packages/accessibility   # 무장애 경로
services/*-adapter       # 서울/경기/인천/시설 API adapter
workers/api-gateway      # 키 보호·캐시·rate limit
workers/collector        # snapshot·품질지표·이력
workers/alert-dispatcher # 장애·지연 알림
```

## 단계별 출시

### MVP

- 지도 배경 UI
- 현재 위치/목적지
- 지하철·버스 통합 도착정보
- 경로 3종 비교
- 혼잡도
- 화장실·엘리베이터
- 데이터 신뢰도 표시

### V1

- 환승·출구·역사 내부 안내
- 막차·장애·공사 알림
- 즐겨찾기
- PWA 설치와 출발 알림

### V2

- 이용자 체감 혼잡 신고
- 시간대별 ETA 보정
- 개인별 접근성 프로필
- 이동 후 경로 품질 평가
